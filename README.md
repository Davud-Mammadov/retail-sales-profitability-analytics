# Retail Sales & Profitability Analytics Project

## 📌 Project Overview
This portfolio project focuses on analyzing retail sales performance, profitability, and customer behavior using a structured relational dataset. The objective is to transform raw retail data into actionable business insights through data cleaning, SQL analysis, and Power BI visualization.

## 📊 Repository Structure
- `excel/` — Contains the raw and cleaned datasets.
- `docs/` — Project documentation, including the data dictionary and data quality logs.
- `sql/` — SQL scripts for data modeling, transformation, and analytical queries.
- `powerbi/` — Power BI dashboard files and visual exports.
- `screenshots/` — Visual previews of the final dashboard and key reports.

## 🔍 Key Business Questions
1. How do sales, profit, and margin change by month?
2. Which products and categories generate the highest profit?
3. Which cities are meeting their sales targets?
4. How do discounts correlate with revenue and profit?
5. Who are our repeat customers, and what is the average order value?
6. Are there any products with sales recorded that lack a valid entry in the product catalog?

## 🛠️ Tools & Technologies
- **Excel:** Initial data exploration, validation, and raw dataset preparation.
- **SQL:** Data querying, aggregation, and relational modeling.
- **Power BI:** Interactive dashboard creation and KPI tracking.
- **Markdown / GitHub:** Project documentation and portfolio presentation.
